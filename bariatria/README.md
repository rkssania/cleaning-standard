# Бариатрия — наблюдение за пациентами

Веб-приложение на Google Apps Script. Данные хранятся в Google Таблице врача.
Требования: [`PRD.md`](PRD.md).

| Страница | Адрес | Кто открывает |
|---|---|---|
| Первичная анкета | `…/exec` | пациент, один раз |
| Ежемесячный контроль | `…/exec?page=checkin` | пациент, раз в месяц |
| Панель врача | `…/exec?page=dashboard&key=<ключ>` | только врач |

## Файлы

| Файл | Что внутри |
|---|---|
| `Code.gs` | сервер: `CONFIG`, маршрутизация, приём форм, проверка данных, расчёт панели |
| `Intake.html` | первичная анкета |
| `Checkin.html` | ежемесячный контроль |
| `Dashboard.html` | панель врача: сводка, поиск, фильтр по статусу, карточка пациента с графиком |
| `Message.html` | страница «Доступ запрещён» |
| `Styles.html`, `Common.html` | общие стили (светлая и тёмная тема) и скрипты форм |
| `appsscript.json` | манифест: часовой пояс Asia/Almaty, доступ «все, без входа» |

## Установка (≈10 минут)

1. Создайте новую Google Таблицу, например «Бариатрия — пациенты».
2. В таблице: **Расширения → Apps Script**.
3. Перенесите файлы:
   - содержимое `Code.gs` — в файл `Код.gs` (заменить целиком);
   - для каждого `.html` файла: **＋ → HTML**, имя **без** `.html`
     (`Intake`, `Checkin`, `Dashboard`, `Message`, `Styles`, `Common`) и вставьте содержимое;
   - манифест: **Настройки проекта → Показывать файл манифеста appsscript.json**,
     затем замените содержимое `appsscript.json`.
4. В `Code.gs` в `CONFIG.DASHBOARD_KEY` впишите свой длинный случайный ключ
   (не короче 12 символов, например `k7Qp2vX9mLr4Tz8w`). Без этого панель не откроется.
5. Выберите функцию `setup` и нажмите **Выполнить** — Google попросит разрешение
   на доступ к таблице. Появятся листы «Пациенты» и «Контроль» с заголовками.
6. **Развернуть → Новое развертывание → Веб-приложение**:
   - «Выполнять как»: **Я**;
   - «У кого есть доступ»: **Все**.
7. Скопируйте URL вида `https://script.google.com/macros/s/…/exec`.
   - пациентам: `…/exec` (анкета) и `…/exec?page=checkin` (контроль);
   - себе в закладки: `…/exec?page=dashboard&key=ВАШ_КЛЮЧ`.

После любых правок кода: **Развернуть → Управление развертываниями → ✎ → Версия: новая → Развернуть**.
Адрес при этом не меняется.

## Как это работает

- **Телефон — идентификатор пациента.** Номер приводится к цифрам; для кода страны `7`
  варианты `8 701 …`, `+7 701 …` и `701 …` считаются одним номером
  (`CONFIG.PHONE_COUNTRY_CODE`, пусто — только цифры). В таблице номер хранится так, как его ввёл пациент.
- Если контроль прислан с номером, которого нет в анкетах, запись всё равно сохраняется,
  пациент видит предупреждение, а в панели она попадает в блок «Записи контроля без анкеты».
  Исправьте номер в таблице — запись привяжется автоматически.
- Повторная анкета с тем же номером обновляет данные пациента, дубль в списке не появляется.
- **Статус контроля** — по дням с последней записи: до 28 — «Норма», 29–35 — «Скоро»,
  больше 35 — «Просрочен», записей нет — «Нет записей» (`CONFIG.SOON_DAYS`, `CONFIG.OVERDUE_DAYS`).
- Карточка пациента: вес до операции → текущий, сброшено (кг и %), %EWL и ИМТ (если указан рост),
  график веса с подсказкой при наведении, последняя запись целиком, история всех записей,
  кнопка «Напомнить в WhatsApp» с готовым текстом и ссылкой на форму.
- Низкие значения анализов подсвечиваются по ориентирам в `Dashboard.html` (`LAB_LOW`):
  гемоглобин < 120 г/л (ж) / < 130 г/л (м), ферритин < 30 нг/мл, витамин D < 30 нг/мл, B12 < 200 пг/мл.
- Вес проверяется в браузере и на сервере (30–350 кг). Текст, начинающийся с `=`, `+`, `-`, `@`,
  сохраняется как текст, а не как формула.
- Столбцы в листах ищутся по заголовкам, поэтому их можно переставлять. Заголовки не переименовывайте.

## Безопасность

- Ключ панели передавайте только врачу. Если ссылка утекла — смените `DASHBOARD_KEY` и сохраните новую версию развертывания.
- Данные лежат в Google-аккаунте врача: включите двухфакторную аутентификацию.
- Таблицу не открывайте для общего доступа — формам это не нужно.
