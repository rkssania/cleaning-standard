# Стандарт уборки таунхауса 210 м²

Мобильный чек-лист для уборщицы: порядок обхода дома, правила гигиены, таймер (норма 3 часа), заявка на закуп и отчёт хозяйке в WhatsApp.

- Один файл [`index.html`](index.html), без библиотек и сервера. Состояние хранится в `localStorage` телефона.
- Языки интерфейса: русский и английский. Отчёт всегда на русском.
- Требования: [`prd.md`](prd.md).

Открыть: https://rkssania.github.io/cleaning-standard/

## Оснащение клиники

[`equipment.html`](equipment.html) — сверка потребности КС с заказом Китая и спецификацией СД (загрузка .xlsx, нечёткое сопоставление названий, выгрузка Excel с цветовой разметкой). Файлы обрабатываются в браузере. Библиотека ExcelJS лежит в `lib/`.
